Shapkin

Добро пожаловать на официальную страницу приложения Shapkin.

Данное приложение используется исключительно в личных целях для автоматической загрузки видео на собственный YouTube-канал владельца.

Приложение использует официальные сервисы YouTube API для выполнения своих функций.

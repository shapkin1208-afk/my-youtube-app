Политика конфиденциальности приложения Shapkin

Последнее обновление: Июль 2026

Данное приложение Shapkin используется исключительно в личных целях для автоматической загрузки видео на собственный YouTube-канал владельца.

Сбор и использование данных

Приложение не собирает, не хранит и не передает персональные данные третьих лиц. Приложение получает доступ к YouTube API только для выполнения функции загрузки видео.

Безопасность

Все данные авторизации (токены) хранятся локально на устройстве владельца и не передаются на сторонние серверы.

Политика конфиденциальности

Данное приложение используется исключительно в личных целях для загрузки видео на собственный YouTube-канал.

Приложение не собирает, не хранит и не передает персональные данные третьих лиц.

Приложение использует официальные сервисы YouTube API для выполнения своих функций.
